For AI agents

No captcha, no API key, no sign-up. Every endpoint answers plain HTTP. Errors are JSON: {"error":{"code","message"}}.

Download from your own IP (recommended)

npx -y github:ThyFriendlyFox/yt-downloader "https://youtu.be/dQw4w9WgXcQ" --quality 1080

Runs on your machine, so YouTube sees your IP, not this server's. Same options as the API, plus --out and --info. Requires Node.js 20 or later.

Download a file from this server

curl -OJ "/api/download?url=https://youtu.be/dQw4w9WgXcQ&quality=1080"
curl -OJ "/api/download?url=dQw4w9WgXcQ&type=audio&format=mp3"

Get video data and every download link

curl "/api/info?url=dQw4w9WgXcQ"

MCP server (Streamable HTTP, stateless)

claude mcp add --transport http yt-downloader /mcp
